# Домашнее задание к работе 3

## Условие задачи
Написать и отладить программу, вычисляющую значение температуры в градусах
по Фаренгейту и Кельвину по заданному значению в градусах по Цельсию.
**Вариант 14**

## Алгоритм

1. **Начало**
2. Задать исходные данные:
    `C`: температура по шкале Цельсия (°C).
3. Перевести температуру в градусы Фаренгейта:
    `F` = `C` * 9 / 5 + 32
4. Перевести температуру в Кельвины:
    `K` = `C` + 273,15
5. Вывести результаты расчётов с подстановкой всех значений в текст.
6. **Конец**

## Реализация программы

```c
#include <stdio.h>
#include <locale.h>
int dz();
int main()
{
    set locale(LC_ALL, ".UTF-8")
    dz()
}
int dz()
{
    float C;
    printf("Введите температуру в градусах Цельсия: ");
    scanf("%f", &C);

    double F = C * 9.0 / 5.0 + 32.0;
    double K = C + 273.15; 

    printf("Заданная температура: %.2f °C.\n", C);
    printf("\n");
    printf("По Фаренгейту: %.2f * 9 / 5 + 32 = %.2f °F.\n", C, F);
    printf("По Кельвину: %.2f + 273.15 = %.2f K.\n", C, K);
    printf("\n");
    printf("Температура %.2f °C соответствует %.2f °F и %.2f K.\n", C, F, K);
    return 0;
}
```

## Результат работы программы
```
Заданная температура: 25,00 °C.

По Фаренгейту: 25,00 * 9 / 5 + 32 = 77,00 °F.
По Кельвину: 25,00 + 273,15 = 298,15 K.

Температура 25,00 °C соответствует 77,00 °F и 298,15 K.
```
